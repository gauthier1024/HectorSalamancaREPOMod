# HectorSalamanca

Adds **Hector Salamanca** as a selectable character in **UmamusumeSemibots**.

## Requirements

- UmamusumeSemibots 2.2.0
- All players in the lobby need both UmamusumeSemibots and this mod.

## Usage

Select the character in Cosmetics > Umas.

Size, rotation and position can be tuned in `BepInEx/config/local.repo.hectorsalamanca.cfg` (restart the game after editing).

## Limitations

The model is static: it follows the body as a single piece, with no limb animation or facial expressions.
